# 江协科技平衡小车

基于 STM32F103 的两轮自平衡小车示例工程。程序读取 MPU6050 的加速度和角速度，估算车身俯仰角，再通过角度、速度和转向三个控制环计算左右电机输出。工程还包含编码器测速、HC-05 蓝牙遥控、按键启停和 OLED 状态显示。

- GitHub 仓库：[kaiture/balancecar-jiangxie](https://github.com/kaiture/balancecar-jiangxie)
- IDE 工程：`Project.uvprojx`（Keil MDK-ARM）
- 主控：工程配置为 STM32F103 系列；具体型号、晶振和下载设置请以 Keil 工程配置及实际板卡为准。

> 这是面向学习和实验的嵌入式工程。电机方向、传感器安装方向、机械平衡点和 PID 参数都与具体车体有关。首次上电应架空车轮，并准备随时切断电机电源。

## 功能

- MPU6050 六轴传感器采样，利用陀螺仪积分和加速度计角度进行互补滤波。
- 角度环进行直立控制，速度环限制前后速度，转向环调节左右轮差速。
- 左右编码器采集轮速。
- HC-05 蓝牙模块接收运动指令，并具备接收超时处理逻辑。
- OLED 显示姿态、控制器参数、速度和蓝牙接收统计信息。
- 按键启动或停止平衡控制；车体倾角超过保护阈值时停止控制输出。
- 以 1 ms 定时中断为系统节拍，实时控制任务按分频周期运行。

## 控制程序如何工作

### 主循环与实时中断

应用入口在 `User/main.c`。主函数先初始化 OLED、MPU6050、HC-05、LED、按键、电机、编码器、调试串口和定时器，然后进入主循环。主循环主要处理按键事件、更新运行状态指示灯和刷新 OLED。

周期性控制放在 `TIM1_UP_IRQHandler()` 定时器更新中断中。中断内的 `Count0` 和 `Count1` 是软件分频计数器：

| 任务 | 分频周期 | 做什么 |
| --- | ---: | --- |
| 系统节拍 | 1 ms | 按键扫描、蓝牙接收状态更新、控制任务分频 |
| 姿态和角度环 | 10 ms | 读取 MPU6050、融合姿态、计算直立控制输出 |
| 速度和转向环 | 50 ms | 读取编码器、计算轮速、更新速度和转向目标 |
| 用户界面 | 主循环 | 处理启停按键并刷新 OLED |

控制代码采用这种分工，是为了让电机控制按稳定周期执行，而屏幕刷新等较慢操作留在主循环里。若中断执行时间超过 1 ms，程序会通过 `TimerErrorFlag` 标记超时，`TimerCount` 可用于辅助观察中断执行耗时。

### 姿态估算：MPU6050 与互补滤波

每次姿态更新时，程序读取加速度计 `AX/AY/AZ` 和陀螺仪 `GX/GY/GZ`。加速度计能根据重力方向估计倾角，但车体振动和运动加速度会影响读数；陀螺仪短时间响应平滑，但直接积分会累积零偏误差。程序将二者融合：

```text
AngleAcc  = -atan2(AX, AZ) × 180 / π + 机械角度补偿
AngleGyro = 上一次 Angle + 陀螺仪角速度 × 采样周期
Angle     = α × AngleAcc + (1 - α) × AngleGyro
```

代码当前使用 `Alpha = 0.01`，也就是约 1% 加速度角度和 99% 陀螺仪积分角度。陀螺仪读数在代码中扣除了固定零偏值；该值和机械角度补偿都需要按实际传感器、安装姿态进行校准。不要只根据示例默认值判断你的车体是否校准完成。

### 三级控制环

程序使用串级控制思路：外层产生内层的目标，最内层直接控制电机。

1. **角度环**：比较当前姿态 `Angle` 与目标角度 `AnglePID.Target`，产生直立所需的平均 PWM。小车前倾时，电机应向前追赶支撑点；方向符号取决于电机安装与传感器坐标系。
2. **速度环**：根据左右轮平均速度 `AveSpeed` 与蓝牙给定速度比较，输出一个角度目标给角度环。前后运动通过小幅倾斜实现。
3. **转向环**：根据左右轮速度差 `DifSpeed` 与蓝牙转向目标比较，输出差分 PWM，使左右轮形成速度差。

左右轮 PWM 由平均量和差分量组合：

```text
AvePWM   = -AnglePID.Out
LeftPWM  = AvePWM + DifPWM / 2
RightPWM = AvePWM - DifPWM / 2
```

两轮输出随后限制在 `-100` 到 `100` 之间，再交给电机驱动函数。符号是否正确必须在架空轮子的条件下先确认：向前倾时，两轮应向前滚动追赶车体。

### 编码器与速度估算

速度环每 50 ms 读取一次左右编码器增量，再按编码器每圈计数、测速时间和减速比换算电机输出轴速度。随后计算：

```text
AveSpeed = (LeftSpeed + RightSpeed) / 2
DifSpeed = LeftSpeed - RightSpeed
```

`AveSpeed` 用于前后速度反馈，`DifSpeed` 用于转向反馈。代码还对接近零的速度设置了死区，降低静止时编码器噪声对控制器的影响。编码器线数、计数方式、方向和减速比如与实际电机不同，需要重新核对换算参数。

### PID 参数与输出限幅

角度环、速度环和转向环的 PID 参数在 `User/main.c` 的 `AnglePID`、`SpeedPID`、`TurnPID` 初始化结构中设置。结构里包括比例、积分、微分参数、输出上下限等；角度环另有输出偏移用于克服小 PWM 下电机难以启动的问题。

当前值是代码中的起始配置，不是适用于所有底盘的通用值。调参时一次只改一个环：先让角度环能稳定扶正，再打开速度环，最后调转向环。检查每个环的输出限幅，尤其是多个控制量叠加后左右电机的最终输出。

## 蓝牙遥控与 OLED 调试

主程序将 HC-05 放在 USART2（PA2/PA3），并调用 HC-05 模块初始化。蓝牙接收与指令解析在模块代码中完成；主程序的 50 ms 速度任务读取 `HC05_Speed` 和 `HC05_Turn` 作为目标量，并在接收超时后依赖模块逻辑清除或复位目标。

仓库主程序的 OLED 页面会显示：

- 角度环的 P/I/D、目标角度、实际角度和输出；
- 速度环的 P/I/D、目标速度、平均速度和角度目标输出；
- 转向环的 P/I/D、目标轮速差、实际轮速差和差分输出；
- 陀螺仪 Y 轴原始读数，以及蓝牙接收字节数和成功指令数。

蓝牙指令的具体格式应以仓库中 HC-05 驱动代码为准。连接不上时，先检查模块配对、串口波特率、TX/RX 交叉连接和共地，再观察接收计数是否变化。

## 编译和烧录

1. 安装 Keil MDK-ARM，并安装工程目标所需的 STM32F1 设备支持包。
2. 下载或克隆仓库，在 Keil 中打开 `Project.uvprojx`。
3. 检查目标 MCU、外部晶振、时钟设置、编译器选项、包含目录和下载器配置。
4. 编译工程，处理与本机工具链或器件包相关的配置差异。
5. 连接调试器烧录固件，首次上电前先检查电源和电机驱动接线。
6. 架空车轮测试传感器角度变化方向、电机追赶方向、编码器正负方向及蓝牙通信。
7. 确认方向正确后再落地调试 PID，并随时准备切断电机电源。

仓库不一定包含与你的板卡完全相同的下载器设置和硬件原理图；如需复现，请以实际开发板、驱动板和接线为准。

## 启动和调试建议

1. **先验证传感器**：静止放置小车，观察 OLED 角度是否稳定；缓慢前后倾斜，确认角度方向符合预期。
2. **校准陀螺仪零偏**：记录车体静止时对应轴的读数，按代码中的零偏补偿方式调整。
3. **检查电机方向**：架空车轮，手动倾斜车体，观察轮子是否向倾倒方向滚动以支撑车体。若方向反了，修正电机通道方向或控制符号。
4. **检查编码器方向和速度比例**：手转左右轮，核对左右速度符号一致且单位换算合理。
5. **单独调角度环**：先让小车具备基本直立响应，再启用速度环和转向环。
6. **逐步扩大测试范围**：先架空测试，再短时间地面测试，最后才测试蓝牙移动指令。

## 常见问题排查

| 现象 | 优先检查 |
| --- | --- |
| 上电后角度快速漂移 | MPU6050 方向、陀螺仪零偏、传感器固定是否牢靠、采样周期 |
| 向一侧倾斜时车轮反向转 | 电机通道方向、角度符号、传感器安装方向 |
| 车体高频抖动 | 角度环增益、机械间隙、传感器振动和电源噪声 |
| 车体缓慢向前或向后跑 | 机械平衡点补偿、速度环反馈方向、左右编码器方向 |
| 两轮速度读数一正一负 | 编码器安装方向与软件方向统一处理 |
| 蓝牙已配对但指令无效 | USART2 引脚、波特率、发送格式、解析计数和超时逻辑 |
| 编译找不到头文件或器件 | Keil 设备包、工程分组、包含路径和工具链版本 |

## 注意事项

- 角度超过保护阈值时，程序会把 `RunFlag` 清零并停止输出。重新扶正后按启停按键恢复运行。
- 初次调试应架空车轮，并降低电源风险；不要在方向、零偏和控制符号未确认时直接落地运行。
- 电机方向、传感器坐标轴、编码器相序、机械平衡点和电池电压都会影响参数。
- 如果修改控制周期，必须同步检查姿态积分周期、PID 调用周期和编码器速度换算周期。
- PID 参数和硬件接线仅供当前工程参考；不同底盘需要自行校准。

## 代码阅读入口

想从代码开始理解时，可以按以下顺序阅读：

1. `User/main.c`：外设初始化、启停逻辑、OLED 数据和 1 ms 控制定时中断。
2. `PID.h` 及 PID 实现文件：PID 状态结构、目标/反馈变量、限幅和每次更新的计算方式。
3. MPU6050 驱动：寄存器初始化、原始数据读取和量程设置。
4. 电机与编码器驱动：PWM 极性、方向控制、计数读取及左右轮正方向约定。
5. HC-05 驱动：串口接收、指令解析、目标速度/转向更新与通信超时处理。
